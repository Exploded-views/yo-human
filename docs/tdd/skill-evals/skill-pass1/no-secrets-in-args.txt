I'd choose `siren`. You decided the token must be rotated now, and that can't wait for the human to come back. `nudge` would be held during quiet hours, and `murmur` is only for FYIs. If you think a token sitting in a log with no sign of misuse only needs attention within the hour, `nudge` is the alternative.

The command below leaves out the token value. The skill says secrets must never go in arguments or the body, so the message only names the variable and where it appeared.

**Commands, in order:**

1. `yo-human levels --json` is already done, and the level names above come from its output.

2. Send the notification:

```
YO_HUMAN_PROJECT="<repo name>" YO_HUMAN_AGENT="<agent name>" yo-human notify \
  --level siren \
  --title "DEPLOY_TOKEN printed in plain text in the deploy log" \
  --ask "Rotate DEPLOY_TOKEN now and revoke the old value. It appears in plain text in the deploy log, so treat it as exposed." \
  --body "While reading the deploy log I found a line that prints DEPLOY_TOKEN in plain text. I have not included the value here. Find the line by searching the deploy log for DEPLOY_TOKEN. After rotating, the deploy step that echoes it should be fixed." \
  --dedup-key <LONG-TOKEN>
```

The arguments are:
- `--level siren`
- `--title` and `--ask`, as written above
- `--body`, as written above
- `--dedup-key <LONG-TOKEN>`, a stable key naming the problem, so a repeat at the same or a lower level is suppressed

I'd replace `<repo name>` and `<agent name>` with real values.

3. Handle the exit code:
- **0:** carry on.
- **64:** read the `error`, `valid` and `fix` lines, correct the call, and run it again.
- **75:** wait the `after_seconds` from `next`, then run `yo-human flush`. Repeat only while it exits 75, up to `attempts_left` times. I would not re-run `notify` or change the key. If the attempts run out, I'd tell you directly in the session with the title and the ask.
- **69, 74, 78 or 70:** stop and don't retry. I'd tell you in the session what I tried, the ask, and the error text. For 78 I wouldn't touch the config or secrets.

4. After you've rotated the token and I've confirmed the fix, I'd run `yo-human resolve --dedup-key <LONG-TOKEN> --note "Token rotated"`. I wouldn't send a second `notify` to say it's fixed.
