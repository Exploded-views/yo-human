**After exit 78 (missing secret `pd-critical`)**

I stop. I run no more commands for this. Specifically:

- I don't run the `fix:` line. It needs the human's 1Password vault and item, which I don't have, and the skill says only the human can fix config and secrets.
- I don't edit the config or set the secret myself.
- I don't retry `notify`. Nothing has changed, so it would fail the same way.
- I don't drop to `nudge` or `murmur`. That would route around the failure and misreport how urgent this is.
- I don't use another tool to reach them, such as email, Slack, or a webhook.

The human has not been reached, so I say that plainly in my reply and handoff. The message would read roughly:

> I could not page you. **Checkout is failing, and this is a siren-level problem.** `yo-human notify --level siren --title "Checkout failing" --ask "Look at checkout now"` exited 78:
>
> ```
> error: secret "pd-critical", used by channels.pager.routing_key, is not set
> valid: a name listed by `yo-human secret list`
> fix: op read "op://<vault>/<item>/<field>" | yo-human secret set pd-critical
> ```
>
> **Ask:** Look at checkout now. Please also set the `pd-critical` secret using the fix line above, filling in your vault, item and field. Until you do, siren pages can't go out.

I would also keep working on the checkout problem within my normal remit, if my own rules allow it.
