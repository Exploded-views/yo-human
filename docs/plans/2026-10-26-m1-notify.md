# M1 v1 Notify Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `yo-human` v0.1.0: agents reach their human through one CLI call, at a level the human configured, over any mix of PagerDuty, ntfy and Bark, within a deadline. Never lost, never twice, never blocking.

**Architecture:** One Go binary, called on demand with no daemon, inside the constitution's layers:
- `cmd → internal/cli → internal/core → internal/store`; core also uses `internal/channel`, the interface every provider implements.
- Configuration (`internal/config`) and secrets (`internal/secrets`) are loaded by the CLI and handed to core.
- All state is plain files under the state directory, written atomically through `internal/store`.
- Providers live in `internal/channel/<type>` and know nothing of core or store.

**Tech Stack:** Go 1.27.3. Dependencies, each pinned in `go.mod` at its newest release that is at least two weeks old, recorded in the commit that adds it:
- `gopkg.in/yaml.v3` (config and secrets)
- `github.com/santhosh-tekuri/jsonschema/v6` (schema validation)
- `github.com/oklog/ulid/v2` (message ids)

Everything else is the standard library: `net/http`, `syscall.Flock` (Linux and macOS only; Windows is out of scope), `context`, `encoding/json`. Tests use `net/http/httptest` fakes, never a live service.

**Spec:** [../specs/2026-10-26-m1-contract-design.md](../specs/2026-10-26-m1-contract-design.md) (signed off in #57). Rules: [../../constitution.md](../../constitution.md). Order: [2026-10-25-roadmap.md](2026-10-25-roadmap.md), M1 waves B–F. M0 ([2026-10-25-m0-scaffold.md](2026-10-25-m0-scaffold.md)) must be merged first: every gate it builds applies to every task here.

## Global Constraints

- Module `github.com/Exploded-views/yo-human`; binary `dist/yo-human`, built `CGO_ENABLED=0 -trimpath`.
- Layers are enforced by the existing depguard rules in `.golangci.yml`:
  - `internal/store` imports no `core` or `channel`.
  - `internal/channel/*` imports no `core`, `store` or `cli`.
  - Channel implementations import no other channel.
  - `problem` is a leaf: it imports no internal package, because `store`, `config`, `secrets`, `core` and `cli` import it. The channel packages do not: the interface package's allow list and the channel-implementations rule both leave it out, so a channel reports a failure as a `channel` error kind, which `core` maps to a problem.
  - `config` and `secrets` may import `channel` (the interface package), `store` and `problem`, but never `core` or `cli`.
  - No internal package but a channel implementation imports `net`, `net/http` (and its subpackages) or `crypto/tls`, outside tests and `*_e2e.go` files. A `*_e2e.go` file must build only with the e2e tag (`//go:build e2e`, or an `&&` chain with a bare `e2e`), a non-test file that builds only with it must be named `*_e2e.go`, and no production package may import an e2e-only package; `internal/repolint`'s `E2EOnly` checks all three under `go test` and in the pre-commit hook, and `scripts/nohooks.sh` checks the release binary.
  - Channel implementations import only the standard library, `internal/channel` and `internal/channel/transport` (the shared network helpers). They never import another implementation.
  - Only `internal/channel/registry` imports a channel implementation (`channeltest` is allowed in tests). `internal/cli` imports neither `store` nor an implementation; it reaches state through `core.State` and the channel types through the registry.
  - These rules are main's `.golangci.yml` (M0's final rules and the per-layer allow lists, `net/` surface and `os/exec` deny of yo-human#64), plus the M1 layering pass's delta: `channel-implementations` is in strict mode and allows `transport`, and `internal-no-network` skips `*_e2e.go`.
- Go files ≤ 400 lines including tests; cyclomatic complexity ≤ 10; per-package coverage floors (`make floors`) for every new package; p95 perf budgets in `perf-budgets.json` (`make perf`).
- Exit codes (spec, verbatim): 0 done; 64 usage; 69 failed (every human-reaching channel rejected it permanently); 70 internal; 74 store I/O; 75 queued; 78 config.
- Statuses (verbatim): `delivered`, `partial`, `queued`, `failed`, `held`, `suppressed`, `resolved`, `noop`; read-only commands print `RESULT ok`.
- The first stdout line is always `RESULT <status> <id>` (`RESULT ok` for read-only commands). `--json` prints the spec's object instead, with `"version": 1`.
- Errors go to stderr as three lines (`error:`, `valid:`, `fix:`), or into the `--json` object as `{"error": {"what", "valid", "fix"}}`.
- Defaults (spec): `deadline: 1s`, `incident_ttl: 24h`, `ask: required`, `quiet_hours: send`, `retry: {every: 60s, times: 5}`.
- Limits (spec): title ≤ 200 characters, body ≤ 16 KB, ≤ 3 actions, dedup key ≤ 255 characters, links http(s) only.
- Paths:
  - user config `$XDG_CONFIG_HOME/yo-human/config.yaml`
  - secrets `$XDG_CONFIG_HOME/yo-human/secrets.yaml` (file 0600, directory 0700)
  - state `$XDG_STATE_HOME/yo-human/` (0700)
  - system config `/etc/yo-human/config.yaml`
  - project config `.yo-human.yaml` or `.yo-human.json`
  - with the XDG fallbacks `$HOME/.config` and `$HOME/.local/state`
- No secret value in any output, error, log line, fixture or RED record. Fake values match `^[A-Z0-9-]*FAKE[A-Z0-9-]*$` (the gitleaks allowlist).
- Test-first per the constitution: a RED record (raw command output plus the exit code, never hand-edited) in `docs/tdd/<topic>-red.txt`, and a mutation record in `docs/tdd/<topic>-mutants.txt`, each with a row in `docs/tdd/README.md`.
- Commits: conventional with a scope, the RED commit marked `(RED)`, each ending with the session's attribution lines.
- Every task that touches secrets, inbound data from providers, or channel isolation gets `needs-security-review` and an independent review before merge (constitution VIII).

## Review Focus

1. **Quiet-hours windows that cross midnight or a DST change.** A 22:00–07:00 window in America/Chicago on 2026-11-01 (the night the clocks fall back) must hold at 23:30 and at 06:30 and release at 07:00 local time. Pinned in Task 4 by `TestQuietWindowAcrossMidnightAndDST`.
2. **Two agents sending the same dedup key at the same moment** must produce exactly one send. Pinned in Task 6 by `TestConcurrentRepeatsPageOnce` (20 goroutines, one fake channel, exactly 1 `Send`).
3. **A process killed mid-send leaves files in `inflight/`.** The next call must return them to the queue after twice the deadline, and only if the pid is gone, never while the owner is alive. Pinned in Task 2 by `TestRecoverStaleInflight` and `TestRecoverSkipsLiveOwner`.
4. **Odd input:** a title with newlines (flattened to spaces), a body over 16 KB on stdin (refused with 64, with the size in the error), non-UTF-8 bytes (refused with 64). Pinned in Task 11 by `TestNotifyInputLimits`.
5. **A secret pasted into a config file as a literal** must fail `config check`, and the error must name the field without echoing the value. Pinned in Task 3 by `TestLiteralInSecretFieldIsRefusedWithoutEcho`.

### Task 2: Store: atomic writes, queue with claim-by-rename, incidents, log, trust records (#28)

**Files:**
- Create: `internal/store/store.go`, `atomic.go`, `queue.go`, `incidents.go`, `trust.go`, and a test file for each

**Interfaces:**
- Consumes: `internal/problem` (Task 1).
- Produces:
  - `func Open(dir string) (*Store, error)`: creates the directory 0700 if missing; refuses one looser than 0700 with a `problem.Storef` whose fix is `chmod 700 <dir>`. Also creates `queue/`, `inflight/` and `dead/`.
  - `func WriteFileAtomic(path string, data []byte, perm fs.FileMode) error`: write a temp file in the same directory, fsync, chmod, rename, fsync the directory.
  - `type Pending struct { Key, IncidentKey string; Data []byte; Attempts int; NextAttempt, DeliverAt time.Time }`. `Key` is `<message-id>.<instance>`; `Data` is opaque JSON from core.
  - `func (s *Store) Enqueue(p Pending) error`
  - `func (s *Store) Due(now time.Time) ([]Pending, error)`: pending entries whose `NextAttempt` and `DeliverAt` are both ≤ now, oldest first.
  - `func (s *Store) Claim(key string) (Claimed, bool, error)`: an atomic rename `queue/<key>.json` → `inflight/<key>.<pid>.json`; `false` if someone else got it first.
  - `func (s *Store) Complete(c Claimed) error`, `func (s *Store) Retry(c Claimed, next time.Time) error` (back to the queue with `Attempts+1`), `func (s *Store) Dead(c Claimed, reason string) error`
  - `func (s *Store) CancelIncident(incidentKey string) ([]Pending, error)`: removes and returns every queued entry for that incident.
  - `func (s *Store) Recover(now time.Time, staleAfter time.Duration) (int, error)`
  - `func (s *Store) Counts() (queued, inflight, dead int, err error)` and `func (s *Store) DeadEntries() ([]DeadEntry, error)`
  - `type Incident struct { Key, Level string; Rank int; Open bool; Reached []Reached; ContentHash, Latest string; Opened, LastSent, Updated time.Time }`, with `type Reached struct { Instance, ProviderID string; Scheduled bool }`
  - `func (s *Store) WithIncidents(fn func(map[string]*Incident) error) error`: an exclusive `flock` on `state.lock` for the whole read-modify-write of `incidents.json`.
  - `func (s *Store) AppendLog(entry any) error` (to `log.jsonl`, mode 0600)
  - `func (s *Store) Trusted(path, sha256 string) (bool, error)` and `func (s *Store) Trust(path, sha256 string) error`

- [ ] **Step 1: Write the failing tests**
  - `TestOpenRefusesLoosePermissions`: a 0755 directory gives a Store-kind problem whose fix contains `chmod 700`.
  - `TestWriteFileAtomicLeavesNoTempOnSuccess`: the directory holds only the target afterwards, with the requested perm.
  - `TestClaimIsExclusive`: 20 goroutines claim the same key; exactly one gets `true`.
  - `TestDueRespectsNextAttemptAndDeliverAt`: an entry with a future `DeliverAt` isn't due until then.
  - `TestRetryIncrementsAttempts`, `TestDeadIsKeptAndListed`, `TestCancelIncidentRemovesOnlyThatIncident`.
  - `TestRecoverStaleInflight`: an inflight file with a dead pid (use pid `2147483646`) older than `staleAfter` returns to the queue.
  - `TestRecoverSkipsLiveOwner`: the same file under `os.Getpid()` is left alone.
  - `TestWithIncidentsSerializes`: two processes (re-exec the test binary with an env flag) each increment a counter 50 times; the total is exactly 100.
  - `TestTrustRoundTrip`: trusting one sha doesn't trust a different sha for the same path.
- [ ] **Step 2: RED** into `docs/tdd/store-red.txt` (raw capture). Commit `(RED)`.
- [ ] **Step 3: Implement.** Use `syscall.Flock(fd, LOCK_EX)`. Process liveness is `syscall.Kill(pid, 0)`. Inflight file names end in `.<pid>.json`.
- [ ] **Step 4: GREEN, lint, mutate.** Mutants: `Claim` copying instead of renaming; `Recover` ignoring pid liveness; `WithIncidents` without the flock. Each must fail a test. Record in `docs/tdd/store-mutants.txt`.

### Task 5: Send pipeline: enqueue first, parallel fan-out under the deadline, statuses, retry, flush (#31)

**Files:**
- Create: `internal/core/pipeline.go`, `deliver.go`, `result.go`, `retry.go`, `flush.go`, and tests

**Interfaces:**
- Consumes: Tasks 1–4.
- Produces:
  - `type Status string` with constants for the eight statuses, plus `StatusOK = "ok"`
  - `type Result struct { Status Status; ID string; Channels []ChannelResult; Next *Next }`
  - `type ChannelResult struct { Channel, Status, Error string }`, where Status is one of `sent`, `queued`, `held`, `dead`, `skipped`, `cancelled`
  - `type Next struct { Do string; AfterSeconds, AttemptsLeft int; Then string }`
  - `type Deps struct { Config *config.Config; Store *store.Store; Channels map[string]channel.Channel; Caps map[string]channel.Capabilities; Now func() time.Time; NewID func() string }`

  - `func (p *Pipeline) Flush(ctx context.Context) (Result, error)`
  - `func NextAttempt(r config.Retry, attempts int, now time.Time) (time.Time, bool)`: the delay is `Every × 2^attempts`, capped at 1h; `false` once `attempts ≥ Times`
  - `func Summarize(results []ChannelResult, reachesHuman map[string]bool) Status`

- [ ] **Step 1: Write the failing tests.** Each is a table-driven test over a scripted `channeltest.Fake`, using `t.TempDir()` stores and a fake clock.
  - `TestEnqueueBeforeSend`: inside `SendFunc`, `store.Counts()` shows the entry inflight (it was written before the network call).
  - `TestAllSentIsDelivered`; `TestOneOfTwoIsPartial` (the failed channel stays queued); `TestNoneReachableIsQueuedWithNext`:
    - `Next.Do == "yo-human flush"`, `AfterSeconds == 60` and `AttemptsLeft == 5` from the level's retry
    - `Then == "tell the human in your session"`
  - `TestAllPermanentIsFailed`: every send `Permanent` → status `failed`, the entries are dead, and the error text survives.
  - `TestLogChannelNeverCountsAsDelivery`: log plus a failing human channel → `queued`, not `partial`.
  - `TestDeadlineBoundsTheCall`: a channel that blocks for 5s and a 200ms deadline. `Notify` returns within 300ms with that channel `queued`, and its context was cancelled.
  - `TestHeldLocallyIsNotSentUntilDue`: status `held`, nothing sent; a `Flush` after `DeliverAt` sends it.
  - `TestScheduledChannelGetsDeliverAt`: a `Schedule` channel receives `SendSpec.DeliverAt` = the window end and returns a scheduled receipt; status `held`.
