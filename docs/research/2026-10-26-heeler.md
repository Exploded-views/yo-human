# Research: Heeler (the iOS console for herdr)

Source: https://github.com/ZingerLittleBee/Heeler (Apache-2.0), read 2026-10-26. Our contribution fork: a planned fork of Heeler.

## What it is

A native iOS app (iOS 18+, iPhone and iPad, SwiftUI) for herdr. It lists the agents running on your machines "sorted by who needs you", lets you read and steer an agent's live terminal, draft in a native Composer, or view the conversation as chat. About 2,900 commits; "built for personal use first, expect rough edges and fast iteration". Not affiliated with herdr.

## How it connects

- Speaks herdr's JSON API over SSH: each request opens a direct-streamlocal channel onto `herdr.sock`; one long-lived channel carries the event stream; interactive terminals run `herdr agent attach --takeover` on an SSH PTY. No server changes beyond SSH access and a running herdr.
- Pairing by QR code: keys are generated on the device, private keys stay in the Keychain, the code pins the host key fingerprint. Supports SSH jump hosts and overlay networks (Tailscale, ZeroTier, EasyTier) inside the app.
- Deep links: `heeler://agent?host=…&session=…&pane=…`.

## Notifications today (what yo-human must improve)

- A herdr plugin (`herdr plugin install ZingerLittleBee/Heeler --ref plugin --yes`) subscribes to `pane.agent_status_changed`.
  - `src/notify-hook.js`: only Blocked and Done notify, per device `notify` flags; debounces about 5 s, re-checks the pane via `herdr agent get <pane>`, dedupes per pane under `HERDR_PLUGIN_STATE_DIR/notify/`.
  - `src/activity-hook.js`: Live Activity counts (working, blocked, done) per host.
- Payload encrypted on the host with AES-256-GCM using a per-host Notification Key (AAD `HERDR-NOTIFY:1`; envelope `{v,kid,n,ct}`; plaintext `pane, kind, status, ts, project?, title?`).
- POSTs to the relay, default `https://heeler-apns.bybee.dev/push` (overridable via `relay_url` in `notify.json`); retries transient failures 3 times; drops tokens on 410.
- The relay (`relay/`, a Cloudflare Worker, no dependencies) is "a dumb pipe on purpose": signs the APNs JWT with a deploy-time .p8, forwards ciphertext, keeps no state. `POST /push`, body ≤ 8 KB; alert path uses `mutable-content: 1` (the app's notification service extension decrypts and rewrites); Live Activity path uses priority 5/10. Rate limits per IP and token (120/60 per min). Self-hostable with your own APNs key and bundle ID.
- **Gaps:** notifications come only from agent status; no custom title/body/level command; no time-sensitive or critical interruption level; no notification actions; answering happens inside the app (Chat view buttons for blocked agents, Composer replies).
